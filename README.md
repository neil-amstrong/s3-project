Project: Launching a "New Testament Challenge" Static Website on Amazon S3
Objectives:
Host a static website on Amazon S3.

Provide a structured plan for reading the New Testament in 21 hours.

Offer resources and tools to help users track their progress.

Deliverables:
S3 Bucket:

Create an S3 bucket named new-testament-challenge.

Website Files:

Upload HTML, CSS, JavaScript, and image files for the website.

Bucket Configuration:

Enable static website hosting.

Set index.html as the index document and error.html as the error document.

Bucket Policy:

Apply a bucket policy to allow public read access.

Website Design:

Homepage with an introduction to the "New Testament Challenge".

Reading plan breaking down the New Testament into 21 one-hour segments.

Resources such as downloadable PDFs, audio files, and links to online Bibles.

Progress tracker for users to mark their completed readings.

Access URL:

Provide the bucket website endpoint URL: http://intern-static-project.s3-website.eu-north-1.amazonaws.com.

Success Factors:
User Engagement:

The website received positive feedback from users who found the reading plan helpful and easy to follow.

Users appreciated the progress tracker and resources provided.

Traffic and Usage:

The website saw a steady increase in traffic as more users shared the challenge with their friends and family.

The structured plan and accessible resources encouraged users to complete the challenge.

Technical Performance:

The website was hosted reliably on Amazon S3 with minimal downtime.

The use of Amazon CloudFront (optional) ensured fast content delivery and improved user experience.

Community Impact:

The project fostered a sense of community among participants who shared their progress and experiences.

The challenge inspired users to engage more deeply with the New Testament.
